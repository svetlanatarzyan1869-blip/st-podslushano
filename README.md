# Подслушано 👂 — расширение для SillyTavern

Стена анонимного паблика ВКонтакте 2017 по вашему сюжету. Соседи, одногруппники и случайные свидетели пишут в предложку о том, что видели. Под постами комментарии, есть опрос, цитаты из пабликов, взаимный пиар. К постам — сохранёнки и песни 2017 года.

Порт плагина «Подслушано» из Tavo.

## Установка
1. SillyTavern → **Extensions** (кубики) → **Install extension**.
2. Вставь ссылку на этот репозиторий → Install, обнови страницу.

## Как открыть
- кружок со Спотти на экране (его можно перетаскивать);
- или ✨ у поля ввода → **Подслушано**.

## Кто пишет стену
В **Extensions → Подслушано 👂**:
- **Модель из подключения таверны** — та же, что пишет чат. Ничего вводить не нужно.
- **Свой провайдер** — отдельная модель: адрес провайдера, ключ и модель. Запрос идёт через прокси на Cloudflare, как в Tavo.

## Кнопки на стене
- **⟳** — свежие записи. Сама стена обновляется раз в N сообщений (по умолчанию 4).
- **Предложить новость** — твоя новость появится постом при следующем обновлении.
- **📢 Пустить в сюжет** — пост незаметно попадёт в следующий ответ бота (один раз).
- **💬** под постом — раскрыть все комментарии или скрыть их.
- Если что-то не так — на карточке ошибки есть «Скопировать подробности».

Светлая и тёмная стена переключаются вместе с темой «ВКонтакте 2017» (расширение 🌓).

## Для правок
- `src/index.template.js` — движок; `src/st-extra.css` — стили только для таверны;
- общие стили, список сохранёнок и песен — в проекте Tavo (`podslushano/src/panel.css`, `album/tags.txt`, `songs.txt`);
- `python3 build.py` собирает `index.js`, `style.css`, `manifest.json`.
